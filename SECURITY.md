# Security

This package decides whether requests come from a genuine app, so a bug in
it can matter more than most.

Please report a vulnerability privately, through GitHub's **Report a
vulnerability** (Security tab), not in an issue. Include what an attacker can
do and, if you can, an input that shows it.

You'll get an answer within a week. Fixes go out as a patch release with a
GitHub security advisory, credited to you unless you'd rather not.

Only the latest release gets fixes.
